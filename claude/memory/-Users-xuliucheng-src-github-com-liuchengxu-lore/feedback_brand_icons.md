description: User prefers the custom MD/PDF file type SVGs over generic Lucide replacements in the sidebar

Keep the custom MD and PDF file type icons (the recognizable markdown "M↓" logo and PDF badge with "PDF" text) as inline SVGs rather than replacing them with generic Lucide `file-text` icons.

**Why:** The brand-style icons are more visually distinctive and recognizable at a glance in the sidebar file list. Generic stroke icons lose that identity.

**How to apply:** When migrating icons to Lucide, only replace generic UI icons (controls, navigation, status). Keep domain-specific brand icons (file type logos, OS logos, GitHub logo) as inline SVGs.
