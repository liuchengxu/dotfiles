# Validation quality

For each changed guarantee, name a plausible
incorrect implementation and the assertion that rejects it. Read setup
and assertions, including tests outside the diff. A missing-test finding
needs a concrete uncovered failure. Use a focused reproduction or mutation
when feasible and authorized. For an unimplemented design, derive checked
acceptance scenarios. Do not substitute passing CI or test counts for this
trace, or claim an unexecuted check passed.
