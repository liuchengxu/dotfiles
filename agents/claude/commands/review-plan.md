# Review the plan: $ARGUMENTS

Use `adversarial-review` as the review coordinator. Use the reviewer the user names. A reviewer may read the
repository with read-only tools. Keep unavailable evidence explicit.

Establish the plan revision, intended decision, governing requirements, and
edit authority from the request. A review-only request makes no plan edits.
Apply clear plan fixes only when already authorized; this never authorizes
implementation or publication.

Retain stable finding IDs and verify each claim against sources. Acknowledged,
accepted, or out-of-scope items need an explicit disposition and its authority;
acknowledgment alone does not close or suppress a blocker.

Finish when the scoped contracts are covered and findings have current
dispositions, or the declared budget ends. Report open findings and coverage
gaps. After authorized fixes, review the affected delta and resolve prior IDs.
Do not repeat general reviews until they return a clean answer. A provider
failure is an execution limitation, not a successful review.
